# WordPress

1. `npm run build` → `dist/hurteemj.min.js`-ийг `integrations/wordpress/hurteemj/` хавтас руу хуулна.
2. `hurteemj` хавтсыг zip болгоод WordPress → Plugins → Add New → Upload.
3. Settings → **Хүртээмж (WCAG)** хэсэгт түвшин, засварын горим, өнгө, мэдэгдлийн URL-ыг тохируулна.

`#wpadminbar` автоматаар шалгалтаас хасагдана. Админ эрхтэй хэрэглэгч самбарын доод хэсэгт "Хөгжүүлэгчийн тайлан"-г харна.
